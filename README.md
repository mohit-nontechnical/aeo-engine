# aeo-engine

A Claude Code plugin that packages a complete GEO/AEO (Generative Engine Optimization /
Answer Engine Optimization) content service: client onboarding, technical audits, topic
research, grounded content generation, quality gates, and answer-engine measurement.

**The design principle: expertise lives in the engine, labor lives with the operator.**
You don't need to know AEO to run this. You run skills in order; the gates catch mistakes.

## Architecture

Two pieces:

1. **The engine (this repo)** — skills + templates. Versioned, shared, contains zero client data.
2. **Client workspaces (one directory per client)** — generated by the `intake` skill. Contains
   everything brand-specific: voice rules, claim ledger, topic registry, measurement evidence.
   The engine never changes per client; only the workspace does.

## Install

```bash
claude plugin marketplace add mohit-nontechnical/aeo-engine
claude plugin install aeo-engine@aeo
```

(Local checkout works too: `claude plugin marketplace add ~/Documents/aeo-engine`.)

## The skills

| Skill | When | What it does |
|---|---|---|
| `aeo-engine:intake` | New client | Guided interview → generates the client workspace (voice kit, claim ledger, boundaries, llms.txt) |
| `aeo-engine:tech-audit` | After intake; quarterly | Technical eligibility audit from a battle-tested defect list (canonicals, sitemap, schema, redirects) |
| `aeo-engine:topics` | After intake; per batch | Buyer-question research → topic registry with AEO notes and grounding-risk flags |
| `aeo-engine:generate` | Weekly cadence | Drafts articles from the registry, grounded in the claim ledger, in the client's voice |
| `aeo-engine:lint` | Every draft | The critic gate: grounding, voice, AEO shape, links. Pass/reject with reasons |
| `aeo-engine:measure` | Baseline + monthly | Frozen prompt panel in ChatGPT Search/Perplexity, evidence archive, honest report |

## Non-negotiables (baked into the skills)

- **No fabrication.** Every public claim traces to a claim-ledger row or a named primary source.
  No invented stats, testimonials, case studies, or quotes — ever.
- **No guarantees.** Activity is guaranteed; rankings, citations, and placement are not.
- **Nothing auto-publishes.** Client approval is explicit and version-specific.
- **Evidence or it didn't happen.** Measurement uses frozen prompts, archived screenshots,
  and visible denominators. Invalid observations are reported, not scored as zero.
